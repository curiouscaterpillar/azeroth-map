# Azeroth Map

A minimal, single-file interactive map of Azeroth. No build step and no dependencies: open `index.html` in a browser.

- Simplified SVG continents (Kalimdor, Eastern Kingdoms, Northrend, Pandaria, Broken Isles, Dragon Isles) and the Maelstrom
- About 50 clickable zones colored by faction, with short descriptions
- Drag to pan, scroll or use the buttons to zoom
- Search box: dims zones that don't match, Enter zooms to the first match

Shapes and positions are stylized for a rough layout, not real geography. Fan project; World of Warcraft and Azeroth are trademarks of Blizzard Entertainment.
